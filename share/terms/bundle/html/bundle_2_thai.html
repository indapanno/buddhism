เมนู
    นำทางคำศัพท์/ชุดศัพท์ที่เกี่ยวข้อง/ยังไม่มีคำแปล

    ยังไม่มีคำแปล

    ขณะนี้ยังไม่มีหน้าชุดศัพท์ที่เกี่ยวข้องฉบับภาษาไทย คุณสามารถแปลเองได้ภายใน 5 นาทีด้วย AI ฟรี โดยไม่ต้องมีความรู้พิเศษ ทำตามขั้นตอนด้านล่าง

    1. เปิดไฟล์ JSON ของหน้านี้: bundle_2_ru.json
    2. ส่งไปยัง AI ฟรีตัวใดก็ได้ พร้อมข้อความ:แปลค่าของคีย์ name และ description ในไฟล์ JSON นี้เป็นภาษาไทย ห้ามแปลหรือเปลี่ยนค่าในอาร์เรย์ terms ส่งผลลัพธ์เป็นบล็อกโค้ด ต้องการไฟล์ JSON เหมือนเดิมแต่เป็นภาษาไทย ห้ามเพิ่มหรือลบสิ่งใด
    3. คัดลอกผลลัพธ์
    4. เปิดโฟลเดอร์ https://github.com/indapanno/buddhism/tree/main/share/terms/bundle/json/
    5. กดปุ่ม “Add file” → “Create new file”
    6. วางคำแปล
    7. ตั้งชื่อไฟล์ว่า bundle_2_thai.json
    8. ส่ง Pull request
    9. รอผู้ดูแลตรวจสอบ เมื่อได้รับอนุมัติ ชุดศัพท์ที่เกี่ยวข้องจะปรากฏบนเว็บไซต์

    สร้างโดยพระอินทปัญโญ จากวัดป่าถ้ำวนนิมิต จังหวัดนครนายก ประเทศไทย เดือนกันยายน ๒๐๒๖. ตัวนำทางประวัติคำศัพท์บาลีเป็นเนื้อหาเสริมสำหรับโพสต์เกี่ยวกับพระพุทธศาสนาที่เผยแพร่ในช่องสาธารณะ «ทำความเข้าใจพระพุทธศาสนา» บนแอปพลิเคชันแม็กซ์ (Max). จำนวนคำศัพท์ในตัวนำทาง: …. เวอร์ชันเว็บแอปพลิเคชัน: ๑.๐.๐. สำหรับนักวิจัยและนักพัฒนา. จำนวนการเข้าชม: 0.
