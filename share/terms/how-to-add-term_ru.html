Как добавить термин

Заметили, что интересного вам термина здесь ещё нет? Вот как его предложить — без специальных технических знаний.

Меню
    Навигатор по терминам / Как добавить термин

    Если вы читатель

    Сначала проверьте поиском на главной странице, что такого термина ещё нет — возможно, он уже добавлен.

    1. Откройте папку с терминами на GitHub. Нужен бесплатный аккаунт GitHub — если его нет, регистрация занимает пару минут.
    2. Нажмите кнопку Fork — это создаст вашу личную копию репозитория, в которой можно свободно редактировать файлы, не затрагивая основной сайт.
    3. Введите термин в поле ниже и нажмите «Скопировать промт» — готовый промт с вашим термином окажется в буфере обмена. Вставьте его в любой бесплатный ИИ (например, Claude, ChatGPT или Gemini) — и получите готовый JSON.

      Затем вставьте промт в любой бесплатный ИИ и получите готовый JSON.

    4. В своей копии репозитория создайте новый файл с именем вида ваш_термин_ru.json (латиницей, без пробелов — например, karuna_ru.json) и вставьте в него JSON, полученный от ИИ, целиком, без изменений.
    5. Сохраните файл — GitHub сам предложит кнопку Create pull request («Предложить изменения»).
    6. Дождитесь проверки. После одобрения термин появится в навигаторе.

    Для администратора сайта

    Создать <id>_ru.json по действующей схеме в share/terms/json/, скопировать HTML-шаблон карточки под тем же именем, обновить json/index_ru.json, закоммитить и запушить.
