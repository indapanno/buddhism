Как перевести термин

Увидели термин без перевода на нужный вам язык? Вот как перевести его за 5 минут — без специальных знаний.

Меню
    Навигатор по терминам / Как перевести термин

    Пошагово

    1. Откройте на GitHub файл термина на языке, с которого переводите — например, dukkha_ru.json — и скопируйте всё его содержимое.
    2. Откройте бесплатный ИИ (например, Claude или ChatGPT) и вставьте туда скопированный текст с просьбой: «Переведи это JSON на тайский язык, сохрани структуру и ключи без изменений, переведи только текстовые значения, а ключ term_ru замени на term_thai».
    3. Проверьте результат — особенно палийские термины (обычно их не переводят, а оставляют в исходном виде или транслитерируют).
    4. На GitHub, в папке share/terms/json, нажмите Fork, чтобы создать свою копию репозитория (нужен бесплатный аккаунт GitHub).
    5. В своей копии создайте файл с тем же именем термина, но с нужным языковым суффиксом — например, dukkha_thai.json — и вставьте туда переведённый текст.
    6. Сохраните файл — GitHub сам предложит кнопку Create pull request («Предложить изменения»).
    7. Дождитесь проверки. После одобрения перевод появится на сайте.

    Для администратора сайта

    Принять Pull Request, проверить валидность JSON и соответствие схеме, скопировать HTML-шаблон карточки под тем же именем (при отсутствии), обновить json/index_thai.json.
