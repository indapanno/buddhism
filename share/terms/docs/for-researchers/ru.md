# Навигатор по истории палийских терминов — для исследователей и разработчиков

Эта страница будет дополнена: технический стек, структура репозитория,
охват собранных терминов, как развернуть сайт самостоятельно на бесплатном
GitHub Pages, и направления для дальнейшего развития проекта.

Пока — по аналогии с соседним проектом [«Ветвление буддизма»](https://github.com/indapanno/buddhism/blob/main/docs/for-researchers/ru.md):
статический сайт на чистом HTML/CSS/JS, без backend, данные о терминах —
в отдельных JSON-файлах.

Репозиторий: https://github.com/indapanno/buddhism
