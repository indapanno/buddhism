วิธีเพิ่มคำศัพท์

พบว่ายังไม่มีคำศัพท์ที่คุณสนใจใช่ไหม? นี่คือวิธีเสนอคำศัพท์ใหม่ — โดยไม่ต้องมีความรู้ด้านเทคนิค

เมนู
    นำทางคำศัพท์ / วิธีเพิ่มคำศัพท์

    สำหรับผู้อ่าน

    ก่อนอื่นตรวจสอบด้วยการค้นหาในหน้าหลักว่ายังไม่มีคำศัพท์นี้อยู่แล้ว

    1. เปิด โฟลเดอร์คำศัพท์บน GitHub ต้องมีบัญชี GitHub ฟรี — หากยังไม่มี การสมัครใช้เวลาเพียงไม่กี่นาที
    2. กดปุ่ม Fork เพื่อสร้างสำเนาส่วนตัวของ repository ที่คุณสามารถแก้ไขได้อย่างอิสระโดยไม่กระทบเว็บไซต์หลัก
    3. กรอกคำศัพท์ในช่องด้านล่าง แล้วกด «คัดลอกพรอมต์» — พรอมต์พร้อมคำศัพท์ของคุณจะถูกคัดลอกไปยังคลิปบอร์ด นำไปวางใน AI ฟรีตัวใดก็ได้ (เช่น Claude, ChatGPT หรือ Gemini) แล้วคุณจะได้ JSON ที่พร้อมใช้งาน

      จากนั้นนำพรอมต์ไปวางใน AI ฟรีตัวใดก็ได้ แล้วคุณจะได้ JSON ที่พร้อมใช้งาน

    4. ในสำเนา repository ของคุณ สร้างไฟล์ใหม่ชื่อ ชื่อคำศัพท์_thai.json (ตัวอักษรละติน ไม่มีช่องว่าง — เช่น karuna_thai.json) แล้ววาง JSON ที่ได้จาก AI ลงไปทั้งหมดโดยไม่แก้ไข
    5. บันทึกไฟล์ — GitHub จะแสดงปุ่ม Create pull request ให้เอง
    6. รอการตรวจสอบ หลังจากได้รับการอนุมัติ คำศัพท์จะปรากฏในตัวนำทาง

    สำหรับผู้ดูแลเว็บไซต์

    สร้าง <id>_thai.json ตามโครงสร้างที่ใช้อยู่ใน share/terms/json/ แล้ว commit และ push

    สร้างโดยพระอินทปัญโญ จากวัดป่าถ้ำวนนิมิต จังหวัดนครนายก ประเทศไทย เดือนกันยายน ๒๐๒๖. ตัวนำทางประวัติคำศัพท์บาลีเป็นเนื้อหาเสริมสำหรับโพสต์เกี่ยวกับพระพุทธศาสนาที่เผยแพร่ในช่องสาธารณะ «ทำความเข้าใจพระพุทธศาสนา» บนแอปพลิเคชันแม็กซ์ (Max). จำนวนคำศัพท์ในตัวนำทาง: …. เวอร์ชันเว็บแอปพลิเคชัน: ๑.๐.๐. สำหรับนักวิจัยและนักพัฒนา. จำนวนการเข้าชม: 0.
