พบว่ายังไม่มีคำศัพท์ที่คุณสนใจใช่ไหม? นี่คือวิธีเสนอคำศัพท์ใหม่ — โดยไม่ต้องมีความรู้ด้านเทคนิค

เมนู
    นำทางคำศัพท์ / วิธีเพิ่มคำศัพท์

    สำหรับผู้อ่าน

    ก่อนอื่นตรวจสอบด้วยการค้นหาในหน้าหลักว่ายังไม่มีคำศัพท์นี้อยู่แล้ว

    1. ไปที่ลิงก์ github.com/indapanno/buddhism/fork แล้วกด Create fork เพื่อสร้างสำเนาส่วนตัวของ repository ที่คุณสามารถแก้ไขได้อย่างอิสระโดยไม่กระทบเว็บไซต์หลัก ต้องมีบัญชี GitHub ฟรี — หากยังไม่มี การสมัครใช้เวลาเพียงไม่กี่นาที
    2. กรอกคำศัพท์ในช่องด้านล่าง แล้วกด «คัดลอกพรอมต์» — พรอมต์พร้อมคำศัพท์ของคุณจะถูกคัดลอกไปยังคลิปบอร์ด นำไปวางใน AI ฟรีตัวใดก็ได้ (เช่น Claude, ChatGPT หรือ Gemini) แล้วคุณจะได้ JSON ที่พร้อมใช้งาน คัดลอก JSON ทั้งหมดรวมทั้งวงเล็บปีกกาต้นและท้าย

      จากนั้นนำพรอมต์ไปวางใน AI ฟรีตัวใดก็ได้ แล้วคุณจะได้ JSON ที่พร้อมใช้งาน

    3. ในสำเนา repository ของคุณ (ไม่ใช่ indapanno/buddhism ต้นฉบับ!) เปิดโฟลเดอร์ share/terms/json → Add file → Create new file ในช่องชื่อไฟล์ให้ใส่ ชื่อคำศัพท์_thai.json (ตัวอักษรละติน ไม่มีช่องว่าง — เช่น karuna_thai.json) แล้ววาง JSON ทั้งหมดที่ได้จาก AI ลงในช่องข้อความใหญ่ โดยไม่แก้ไข (หากสะดวกกว่า สามารถบันทึก JSON เป็นไฟล์ในเครื่องแล้วอัปโหลดผ่าน Add file → Upload files แทนได้ ผลลัพธ์เหมือนกัน)
    4. เลื่อนลงไปที่ส่วน Commit changes แล้วเลือก Create a new branch for this commit and start a pull request ให้แน่ใจ — ไม่ใช่ «Commit directly to the main branch» มิฉะนั้นการเปลี่ยนแปลงจะอยู่แค่ในสำเนาของคุณ ไม่ถูกเสนอไปยังเว็บไซต์หลัก แล้วกดปุ่มสีเขียว
    5. จะเปิดหน้าเปรียบเทียบขึ้นมา ตรวจสอบบรรทัด base repository ด้านบน — ต้องแสดงเป็น indapanno/buddhism หากแสดงเป็น fork ของคุณเองแทน ให้กดลิงก์ compare across forks แล้วเลือกด้วยตนเอง: ด้านซ้าย base repository: indapanno/buddhism, base: main และด้านขวาเลือก fork และ branch ที่เพิ่งสร้าง จากนั้นกด Create pull request อีกครั้ง
    6. รอการตรวจสอบ หลังจากได้รับการอนุมัติ คำศัพท์จะปรากฏในตัวนำทาง

    สำหรับผู้ดูแลเว็บไซต์

    สร้าง <id>_thai.json ตามโครงสร้างที่ใช้อยู่ใน share/terms/json/ แล้ว commit และ push

    สร้างโดยพระอินทปัญโญ จากวัดป่าถ้ำวนนิมิต จังหวัดนครนายก ประเทศไทย เดือนกันยายน ๒๐๒๖. ตัวนำทางประวัติคำศัพท์บาลีเป็นเนื้อหาเสริมสำหรับโพสต์เกี่ยวกับพระพุทธศาสนาที่เผยแพร่ในช่องสาธารณะ «ทำความเข้าใจพระพุทธศาสนา» บนแอปพลิเคชันแม็กซ์ (Max). จำนวนคำศัพท์ในตัวนำทาง: …. เวอร์ชันเว็บแอปพลิเคชัน: ๑.๐.๐. สำหรับนักวิจัยและนักพัฒนา. จำนวนการเข้าชม: 0.
