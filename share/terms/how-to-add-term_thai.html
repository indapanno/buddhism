วิธีเพิ่มคำศัพท์

พบว่ายังไม่มีคำศัพท์ที่คุณสนใจใช่ไหม? นี่คือวิธีเสนอคำศัพท์ใหม่ — โดยไม่ต้องมีความรู้ด้านเทคนิค

เมนู
    นำทางคำศัพท์ / วิธีเพิ่มคำศัพท์

    สำหรับผู้อ่าน

    ก่อนอื่นตรวจสอบด้วยการค้นหาในหน้าหลักว่ายังไม่มีคำศัพท์นี้อยู่แล้ว

    1. ไปที่ลิงก์ github.com/indapanno/buddhism/fork แล้วกด Create fork เพื่อสร้างสำเนาส่วนตัวของ repository ที่คุณสามารถแก้ไขได้อย่างอิสระโดยไม่กระทบเว็บไซต์หลัก ต้องมีบัญชี GitHub ฟรี — หากยังไม่มี การสมัครใช้เวลาเพียงไม่กี่นาที
    2. กรอกคำศัพท์ในช่องด้านล่าง แล้วกด «คัดลอกพรอมต์» — พรอมต์พร้อมคำศัพท์ของคุณจะถูกคัดลอกไปยังคลิปบอร์ด นำไปวางใน AI ฟรีตัวใดก็ได้ (เช่น Claude, ChatGPT หรือ Gemini) แล้วคุณจะได้ JSON ที่พร้อมใช้งาน คัดลอกคำตอบของ AI ทั้งหมด รวมทั้งวงเล็บปีกกาต้นและท้าย

      จากนั้นนำพรอมต์ไปวางใน AI ฟรีตัวใดก็ได้ แล้วคุณจะได้ JSON ที่พร้อมใช้งาน

    3. ในสำเนา repository ของคุณ (ไม่ใช่ indapanno/buddhism ต้นฉบับ!) เปิดโฟลเดอร์ share/terms/json แล้วกด Add file → Create new file
    4. ในช่องชื่อไฟล์ ให้ใส่ค่าของคีย์ "id" จาก JSON ที่ได้รับ ตามด้วย _thai.json (ตัวอักษรละติน ไม่มีช่องว่าง) เช่น หาก JSON เขียนว่า "id": "karuna" — ชื่อไฟล์คือ karuna_thai.json
    5. วาง JSON ทั้งหมดลงในช่องข้อความใหญ่ด้านล่าง โดยไม่แก้ไข (หากสะดวกกว่า สามารถบันทึก JSON เป็นไฟล์ในเครื่องแล้วอัปโหลดผ่าน Add file → Upload files แทนได้ ผลลัพธ์เหมือนกัน)
    6. กดปุ่มสีเขียว Commit changes... ที่มุมขวาบนของหน้า — จะมีหน้าต่างแยกเปิดขึ้นมา
    7. ในหน้าต่างที่เปิดขึ้นมา ช่อง Commit message ไม่ต้องแก้ไข ⚠️ ต้องเลือกตัวเลือกด้านล่างเป็น «Create a new branch for this commit and start a pull request» ให้แน่ใจ — ค่าเริ่มต้นคือ «Commit directly to the main branch» ซึ่งผิด เพราะจะส่งไฟล์เข้าสำเนาของคุณโดยตรง ไม่เสนอการเปลี่ยนแปลงไปยังเว็บไซต์หลัก จากนั้นกดปุ่มสีเขียว Commit changes ด้านล่างหน้าต่าง
    8. จะเปิดหน้าเปรียบเทียบ («Comparing changes») ตรวจสอบบรรทัด base repository ด้านบน — ต้องแสดงเป็น indapanno/buddhism หากใช่ ให้ไปขั้นตอนถัดไป
      หากแสดงเป็น fork ของคุณเอง หรือหน้าเปรียบเทียบไม่เปิดขึ้นมาเลย (แปลว่าขั้นตอนก่อนหน้าเลือกตัวเลือกผิดโดยไม่ตั้งใจ) ให้เปิดที่อยู่นี้ด้วยตนเอง: github.com/indapanno/buddhism/compare/main...ชื่อผู้ใช้ของคุณ:buddhism:ชื่อบรานช์ โดยแทนที่ «ชื่อผู้ใช้ของคุณ» ด้วยชื่อบัญชี GitHub ของคุณ และ «ชื่อบรานช์» ด้วยชื่อบรานช์ที่สร้างขึ้น (หากไฟล์ไปอยู่ที่ main ของสำเนาคุณโดยไม่ได้ตั้งใจ ให้ใส่ main แทนชื่อบรานช์)
    9. กดปุ่มสีเขียว Create pull request เพิ่มคำอธิบายได้ตามต้องการ แล้วกดปุ่มเดิมอีกครั้งในหน้าถัดไป
    10. รอการตรวจสอบจากผู้ดูแล หลังจากได้รับการอนุมัติ คำศัพท์จะปรากฏในตัวนำทาง

    สำหรับผู้ดูแลเว็บไซต์

    สร้าง <id>_thai.json ตามโครงสร้างที่ใช้อยู่ใน share/terms/json/ แล้ว commit และ push

    สร้างโดยพระอินทปัญโญ จากวัดป่าถ้ำวนนิมิต จังหวัดนครนายก ประเทศไทย เดือนกันยายน ๒๐๒๖. ตัวนำทางประวัติคำศัพท์บาลีเป็นเนื้อหาเสริมสำหรับโพสต์เกี่ยวกับพระพุทธศาสนาที่เผยแพร่ในช่องสาธารณะ «ทำความเข้าใจพระพุทธศาสนา» บนแอปพลิเคชันแม็กซ์ (Max). จำนวนคำศัพท์ในตัวนำทาง: …. เวอร์ชันเว็บแอปพลิเคชัน: ๑.๐.๐. สำหรับนักวิจัยและนักพัฒนา. จำนวนการเข้าชม: 0.
